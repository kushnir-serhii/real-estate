# 009 — SEO

**Status:** in-progress · **Depends on:** 005, 007 · **Route(s):** all public, `/admin/pages`

## Goal
Every public page has correct title, description, canonical and structured data; Google gets a fresh sitemap — without manual keyword work. The admin edits static pages and their SEO.

## Scope
- In: structured title/description templates for properties (manual SEO fields always win); SEO fields, text and `noindex` for static pages (admin `/admin/pages`); `sitemap.ts`, `robots.ts`, canonical, `og:locale`, Open Graph image (property photo, branded static fallback), schema.org JSON-LD; an empty redirect map for the old WordPress site (skeleton); fail loudly when `NEXT_PUBLIC_SITE_URL` is missing in a production build.
- Out: keyword analysis, blog, landing URLs for filter combos (postponed, see Open questions), generated OG images (`next/og`, too heavy for Workers), Product rich results (Google has none for real estate).
- Already done in 004/005 (don't redo): canonical, `noindex` for filtered catalog URLs (`?deal=X` and plain `/catalog` are indexed), sold-page `noindex`, SEO fields for properties in the admin (008).

## Decided (2026-10-29, after an SEO specialist review)
- **Title (property, SEO title empty):** `{Тип}, {N}-кімн., {площа} м², {район}, {місто}` plus ` — {ціна}` for sale only; the brand is appended by the root template only if the whole title stays about ≤ 60 chars, else the title is `absolute`. **Description (SEO description empty):** a sentence from the facts + a short call to action, 120–155 chars. The description text is no longer used as the fallback. Manual SEO fields always win.
- **JSON-LD:** sitewide `Organization` + `RealEstateAgent` (name, url, logo, phone, address, hours — same NAP as the footer); property page `BreadcrumbList` + `RealEstateListing` whose `mainEntity` is a `Residence`/`Apartment`/`House` (floor size, rooms, address down to the district, never the house number) with `offers` (`price` as a number, `priceCurrency`, `availability`); catalog `BreadcrumbList`. No `Product`, no Offer on sold pages. Serialized with `<` escaped. Accepted with validator.schema.org (syntax); the Rich Results Test is optional.
- **Sitemap:** published properties (`lastModified` = real `updated_at`), static pages that are not `noindex`, `/catalog`, `/catalog?deal=…`. No `changefreq`/`priority`. Refreshed through the `properties` and `pages` cache tags.
- **Robots:** allow `/`, disallow `/admin` and `/api`, `sitemap:` line. Filter params stay `noindex, follow` + canonical (not blocked, so Google can read the noindex).
- **OG:** first property photo, else a static branded image; `twitter: summary_large_image`; `og:locale` `uk_UA`.
- **Redirects:** an empty typed map `src/constants/redirects.ts` (old path → new path) applied with a 301, with a test. Filled when a list of old URLs exists (the old site may be gone).
- **Admin pages:** home, about, contacts, privacy: title, Markdown body, SEO title/description with length counters and a SERP preview, a `noindex` switch, «Скинути до стандартного»; the privacy draft flag moves from code to a setting.

## Data
`properties.seo_*`, `pages` (+ `noindex boolean` and a `settings` key for the privacy draft flag, new migration).
