# 009 — SEO

**Status:** draft · **Depends on:** 005, 007 · **Route(s):** all public

## Goal
Every public page has correct title, description, canonical and structured data; Google gets a fresh sitemap — without manual keyword work.

## Scope
- In: title/description templates for properties with manual override; SEO fields for static pages (admin `/admin/pages`); `sitemap.ts`, `robots.ts`, canonical, Open Graph images, schema.org (`RealEstateAgent`, `Offer`/`Product`/`Residence` for properties, `BreadcrumbList`).
- Out: keyword analysis, blog.

## Data
`properties.seo_*`, `pages`.

## Slices

### [ ] 1. Templates + metadata
- **Agent:** backend
- **Accept:**
  - [ ] every property has a unique title/description from the template unless overridden

### [ ] 2. Sitemap, robots, canonical, schema.org
- **Agent:** backend
- **Accept:**
  - [ ] sitemap lists only published properties and pages; admin and filters-with-params are not indexed
  - [ ] schema validates in Google's Rich Results test (manual check by the user)

### [ ] 3. Admin: pages + SEO fields
- **Agent:** designer
- **Accept:**
  - [ ] editing a page revalidates it

## External needs
- Domain; Google Search Console access for the client.
