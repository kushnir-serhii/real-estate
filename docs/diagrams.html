UML diagrams

Diagrams of how the 7 SKY real estate project is built around Supabase and Plektan, and where the mock data lives. They are written in Mermaid (GitHub and the VS Code Markdown preview render it) and describe the code as of spec 015. Product context: product.md.

This file is the single source. docs/diagrams.html is generated from it: a self-contained viewer (no network, opens by double-click) where hovering or focusing any block shows a small tooltip with its marker and a short description. Elsewhere, for example on GitHub, the same text is in the «Blocks» table under each diagram.

Hover a block, or Tab to it, to read what it is. Esc closes the tooltip.

Legend

Every block carries one marker, written as text in its label (never by colour alone) and in the «Data» column of its table.

MarkerMeaning
realThe production path: Supabase Postgres with RLS, Supabase Auth, R2, the live Plektan, Telegram, LLM, Turnstile and geocoder calls. Wired in code, not connected to any account yet.
mockExists only for demo or fixture mode: the in-memory store, the typed seed, the demo session cookie, in-memory photo uploads, service fixtures, the agency constants and the generated supabase/seed.sql.
seamCode that serves both worlds and picks one by env: the src/lib/db/* facades, each service client's entry, admin-session.ts and photo-url.ts.

A dash in the «Data» column means the block holds no data (a person or a trigger). In the diagrams a mock block has a dashed border and a dotted arrow leads to it.

Blocks tables

Under every diagram there is a table with one row per block:

ColumnContent
BlockThe key that matches the block in the Mermaid source: the node id in a flowchart, the class name in a class diagram, the participant or actor alias in a sequence diagram, the state id in a state diagram.
Datareal, mock, seam or a dash.
What it isOne plain sentence of at most 140 characters. It is the tooltip text.
CodeThe path in the repo and the env variable that switches the block, if any. Shown in the table only.

pnpm diagrams fails when a block has no row, when a row matches no block, or when a sentence is longer than 140 characters.

Regenerating the viewer

pnpm diagrams

The generator reads this file, renders each diagram with Mermaid in the Playwright Chromium (offline, nothing is downloaded), checks the tables against the diagrams and writes docs/diagrams.html, which is committed. Edit this file, run the command, commit both files.
